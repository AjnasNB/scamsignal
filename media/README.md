# ScamSignal + AppPassport media

Public presentation assets for the APK evidence demo at
https://scamsignal.ajnasnb.com.

- `brand/scamsignal-mark.png`: transparent logo.
- `images/`: original generated illustrations for India, APK evidence, and independently readable records.
- `deck/scamsignal-pitch-deck.pptx`: six-slide editable presentation.
- `deck/slide-1.png` through `slide-6.png`: presentation previews.
- `video/scamsignal-explainer.mp4`: narrated motion graphics explainer.
- `video/poster.png`: video cover image.

The visual artwork was generated for this project. Music was originally synthesized for the film. Narration is synthetic, generated locally with [Kokoro](https://github.com/hexgrad/kokoro) (Apache 2.0) using [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx) (MIT). The film uses [Source Serif 4](https://github.com/adobe-fonts/source-serif) and [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), both under the SIL Open Font License. Fonts and model weights are not redistributed in these finished media files.

The presentation's five APK examples come from measured static analysis. InsecureBankv2 and PIVAA are intentionally vulnerable training applications, not confirmed malware. Signature verification and permission declarations do not establish application safety. New scans require the analysis service; existing public warning records can be read independently.
